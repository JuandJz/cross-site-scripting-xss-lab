🔍 Laboratorio de XSS

Aprende sobre vulnerabilidades Cross-Site Scripting en un entorno seguro

¿Qué es XSS (Cross-Site Scripting)?

XSS es una vulnerabilidad de seguridad web que permite a atacantes inyectar código JavaScript malicioso en páginas web vistas por otros usuarios. Este laboratorio te enseñará los tres tipos principales de XSS:

  • Reflected XSS: El código malicioso se refleja inmediatamente en la respuesta
  • Stored XSS: El código se almacena y ejecuta cada vez que se carga
  • DOM-based XSS: La vulnerabilidad está en el código JavaScript del cliente

Ejercicios Disponibles

EJERCICIO 1

🔄 Reflected XSS

Explota una vulnerabilidad de búsqueda que refleja el término buscado sin sanitizar. El código se ejecuta inmediatamente pero no persiste.

💡 Payload Sugerido:
<script>alert('XSS Reflected!')</script>

💾 Stored XSS

💡 Payload Sugerido:

📚 Recursos Adicionales
  • Visita la página de Usuarios de Prueba para ver datos que podrías "robar" con XSS
  • Usa las herramientas de desarrollador de tu navegador (F12) para inspeccionar el código
  • Los payloads más simples suelen ser los más efectivos
  • Recuerda: esto es solo para aprendizaje, nunca uses XSS en sitios reales sin permiso
💡 Tips para Principiantes
  • Empieza simple: Usa payloads básicos como <script>alert(1)</script>
  • Observa el código: Usa "Ver código fuente" para entender cómo se renderiza tu input
  • Prueba variaciones: Si un payload no funciona, intenta con eventos diferentes (onclick, onerror, onload)
  • Usa la consola: La consola del navegador te mostrará errores de JavaScript
